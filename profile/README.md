**无人农场世界模型与 UE 高逼真仿真**

MetaEvo Lab 子项目 · [实验室主页](https://metaevo.github.io/)

## 🌟 欢迎

本仓库是无人农场UE世界模型项目组的公开主页。组内的工作、进展与产出在此选择性地同步，欢迎交流。

## 😎 我们是谁

我们是 [MetaEvo Lab](https://metaevo.github.io/)（MetaEvolution Lab）下的无人农场UE世界模型项目组。

## 🎯 研究目标

- 构建符合物理规律的农场仿真环境，覆盖无人机群、与地块等
- 在该环境中训练管理农场作业的智能体，使其在观测受限时仍能完成决策
- 沉淀可复现、可公开发布的评测基准与数据集

## 🔬 研究工作

### 世界模型

面向部分观测条件，预测环境的全局状态与细节变化，并向智能体输出风速、偏移度等观测量；梳理 2018 年以来的代表性工作，建立可检索的论文库并定期同步新知

### 仿真环境

参照市面机型参数设定无人机自身状态（电量、载重等），构建无人机群、与地块等，预留观测接口；采用UE进行可视化展示等

### 模拟器

调研市面现有三至四款主流无人机模拟器，分析其实现原理、部署方式与优缺点，并完成本地部署、代码调试与效果观察

## 🗓 技术路线

| 阶段 | 内容 | 产出 |
| :-- | :-- | :-- |
| 调研摸底 | 分工落实，三条线并行推进 | 文献库、模拟器对比、引擎入门样例 |
| 框架搭建 | 基于调研结论搭建仿真框架，对接观测接口 | 可运行的仿真场景 |
| 模型训练 | 在环境中训练智能体 | 世界模型与智能体 |
| 雏形与评测 | 农场雏形搭建，数据集构建 | 演示视频、评测基准、论文 |
